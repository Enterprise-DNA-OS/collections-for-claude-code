# Why there is no front end

The database stores the collection. Claude Code, Codex, OpenCode or Cursor uses the same CLI and command recipes. A registrar can ask for the loan list, inspect the evidence and record a move.

Static HTML reports are read-only output, not a public catalogue, phone app or live collaborative workspace. They do not provide barcode scanning, offline field capture, media viewing, drag and drop or per-user permissions. Exact locations and private donor records must remain private. HTML paperwork can be printed, but signatures and approved terms are separate.

A shared deployment needs authenticated registrar access, backups, restore rehearsals and collection-specific permissions. Enterprise DNA can build screens and connections into your own version through Omni by Enterprise DNA. The free base does not supply those services.
