# Collections for Claude Code: operating instructions

Read README.md, docs/cli.md and docs/compliance.md. This is a registrar's collection database, not a public catalogue. All demo records are fictional.

## Rules

- Start with a current CLI read. Never invent provenance, rights, inspection dates, approvals or permissions.
- Record actual movements with the mover, authoriser and reason. Show ambiguous matches and stop.
- Drafts remain in drafts/ and docs-out/. No command sends, publishes or arranges transport.
- Compliance reports check selected evidence only. A clear report does not certify Spectrum compliance, export legality, title, insurance or safe conservation treatment.
- Keep donor details, exact locations, sensitive collection knowledge and exports private. Use a trusted registrar role. No anonymous database access.
- Add corrections as notes. Movement and inspection history is append-only. Keep source exports and reconcile before replacement.
- Use a new migration for a change. Test with disposable data, never seed a live collection. Back up before importing.
- One library for every agent. AGENTS.md routes here. See docs/command-library.md for every recipe.
